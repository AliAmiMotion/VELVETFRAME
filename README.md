# VELVET FRAME

Static storefront with interactive 3D eyewear previews.

## Hosting

Deploy this directory on Vercel with the Other framework preset, no build or install command, and the repository root as output directory.

## Commerce status

The connected Shopify store is velvet-frame-5.myshopify.com. Its catalog was empty when checked on 2026-10-26. The local basket is a prototype; checkout is not connected. Import and verify the selected CJ products before mapping their Shopify variant IDs and enabling checkout. The USD/GEL amounts in the storefront are prototype prices, not synchronized prices.

## Assets

The GLB models use KHR_draco_mesh_compression, supported by the model-viewer component used on the product pages. Uncompressed originals and unused design drafts are kept outside this repository. Preserve the current materials and appearance when making further optimizations.

## Local preview

Serve this folder with an HTTP static-file server. No application dependencies or build step are required.
